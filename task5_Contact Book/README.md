# Contact Book Application (Python)

This project is a **menu-driven Contact Book application** developed as **Task 5** for the CodSoft Python Internship.

The application allows users to store, manage, and search contact information using a simple and user-friendly command-line interface.

---

## 📌 Features

- Add new contacts with:
  - Name
  - Phone Number
  - Email Address
  - Address
- View a single contact’s full details
- View all saved contacts (name + phone number)
- Search contacts by name
- Update existing contact details
- Delete contacts
- Menu-driven, easy-to-use interface

---

## 🛠 Technologies Used

- Python
- Dictionaries for data storage
- Command-Line Interface (CLI)

---

## ▶ How to Run

1. Make sure Python is installed on your system.
2. Clone the repository or download the project files.
3. Run the program using:
